# AI-Powered Chatbot

An AI-powered conversational web application built with Python, Flask, SQLite, and Groq Cloud AI. The application provides an interactive chat interface with user authentication and persistent conversation history.

## Features

- AI-powered conversational responses
- User registration and authentication
- Persistent chat history using SQLite
- Flask-based backend
- REST API integration
- Responsive web interface
- Conversation management
- Error handling and API response processing

## Technologies Used

- Python
- Flask
- SQLite
- Groq Cloud AI
- HTML5
- CSS3
- JavaScript
- REST APIs
- Git & GitHub
